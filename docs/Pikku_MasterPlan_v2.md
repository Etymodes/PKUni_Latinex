## 1. 项目定位

哔丘 Pikku 是一个面向多语言学习、复习和考试模拟的网页平台。

项目不再只服务于北京大学拉丁语水平考试，但继续完整保留原有拉丁语功能、题库、资料体系和“比丘拟”概念。第一版支持：

- 拉丁语模式：比丘拟 · PKUni Latinex
- 日语模式：JLPT N4、N3、N2、N1
- 西班牙语模式：CEFR A1、A2、B1、B2、C1、C2

核心原则：

1. 一个 Pikku 账号学习多种语言。
2. 每种语言拥有自己的等级、题型、词汇统计和考试模式。
3. 登录、进度、收藏、错题、管理后台和基础界面共用。
4. 拉丁语现有功能不降级、不丢失、不一次性重写。
5. 先实现能使用、能测试、能部署的最小多语言版本，再逐步扩充内容。

## 4. 最小多语言架构

### 4.1 不进行的改造

第一版不做：

- 不换前端框架
- 不新建第二个仓库
- 不引入额外状态管理库
- 不建立微服务
- 不建立独立图数据库
- 不建立复杂插件系统
- 不为了多语言重写现有拉丁语页面

### 4.2 语言代码

```ts
type LanguageCode = "la" | "ja" | "es";
```

### 4.3 语言配置

采用一张配置表驱动模式切换：

```ts
type LanguageConfig = {
  code: LanguageCode;
  name: string;
  nativeName: string;
  levels: string[];
  defaultLevel: string;
};
```

首批配置：

```ts
const languages = {
  la: {
    name: "拉丁语",
    nativeName: "Latīna",
    levels: ["elementary", "intermediate", "mixed", "advanced"],
  },
  ja: {
    name: "日语",
    nativeName: "日本語",
    levels: ["N4", "N3", "N2", "N1"],
  },
  es: {
    name: "西班牙语",
    nativeName: "Español",
    levels: ["A1", "A2", "B1", "B2", "C1", "C2"],
  },
};
```

### 4.4 题目最小扩展字段

在现有题目结构上增加：

```ts
language: "la" | "ja" | "es";
level: string;
skills?: string[];
source?: string;
sourceStatus?: "original" | "adapted" | "public-domain" | "licensed";
```

兼容规则：

- 旧题目没有 `language` 时一律按 `la` 处理。
- 原有拉丁语难度字段继续可用。
- 不一次性迁移全部旧数据。
- 新题目必须显式写入语言和等级。

### 4.5 学习记录

错题、收藏和进度至少按以下键区分：

```text
user_id + language + question_id
```

词汇统计至少按以下键区分：

```text
user_id + language + lemma
```

这样可避免不同语言的题目、词汇和等级互相污染。

- 有序选题
- 随机练习
- 自适应背单词
- 词汇量测试

自适应背词首版规则：

- 拉丁语、日语、西班牙语都按当前等级筛词；拉丁语“混合难度”合并初级和中级。
- 不设每日训练数量上限，用户可持续点击“记得／忘了”进入下一词。
- 未见词保持较高探索权重；错误率高的词提高权重；熟词降低但不永久移除；最近四张词卡暂时降权。
- 个人设置提供“纯单词记忆”和“纯单词＋语境”两种模式；语境模式只显示一条短例句，不提前暴露释义。
- 游客记录保存在本机；登录后按账号和语言写入 `vocab_stats_by_language`，显示模式写入账号偏好。
- 公开资料只证明词灵 Cling 宣称“无限背单词、个性化推词、造句”；没有找到其公开源码或足以复现的算法说明。Pikku 使用自己的透明权重，不声称复制 Cling 的强化学习或“最优”算法。
- 调研入口：`https://www.clingword.com/`、`https://www.bilibili.com/video/BV1J4EjzyExE/`。
