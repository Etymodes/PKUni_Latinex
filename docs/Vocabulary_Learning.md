# 联动词库与个人记忆预测

本轮范围同时包括用户指定的《N1必背2000词PDF》和1992年旧1级试卷涉及的词汇。题库、词表和预测功能已通过 PR #23 于2026-10-07按用户明确授权合并并发布到 pikku.qzz.io，生产应用提交为1a2f0205a99f37e9502aeeeff4c4ad8470c9bc53。

## 同一词条，两种使用方式

`data/vocabulary.ts` 是词典与背单词的共同入口。已有词卡保留 ID 和 `语言:词头` 学习记录键；日语新增词按规范化词头合并，重叠词同时保存 PDF 页码和试卷题号。词义、读音存在差别时保留来源释义及异读，不能为了去重静默覆盖。

- 词典可以直接打开该词的练习；背词可以返回同一词条，查看累计次数及最近反馈。
- 背词释义和词典隐藏PDF名称/页码、试卷题号、导入批次及原始来源备注；多读音、释义、用法和异写用中性字段展示，来源信息仍保存在数据中。词典不再提供来源/批次筛选；背词范围选择仍可指定词集。保留已有大辞典核验状态，以及発足的《大辞泉》读音引用，不把中文简释或泛称“按词典”包装成已核。
- 纯查词不增加反馈，明确选择“忘了／近似／记得”才写学习事件。“近似”表示有印象但语义判断与释义有偏差，独立记录，不并入忘记或完全记得；词典显示近似次数及最近状态。
- “1992真题词汇”“2000词”和“全部词库”可跨级选词；“当前等级及以下”只包含已分级词条。
- 1992词汇表含295个去重词头，逐词评定为 C 9／F 189／G 97／M 0，覆盖65道词汇题目标及正确项，并补充131个语境词。所有149道原题都有词条关联，不声称穷尽全文分词。
- PDF 230页提取2014条主词条，按词头合并为2013词；与1992词表重叠53词，两来源并集2255词。
- PDF 名称中的 N1 是来源标签。尚未逐词完成 CFGM 审核的词条标为“待分级”，仍可通过来源范围和词典正常练习，不自动映射为 M。
- PDF 提取、实际条数及检查记录见 `N1_Vocabulary_Import.md`。不上传整份 PDF，也不编造缺失的例句。

## 可从实际反馈学习的模型

`lib/vocabulary-model.ts` 的 v2 实现按账号、按语言使用的小型三分类在线模型；没有第三方模型服务或新依赖。输入包括复习间隔、重复次数、历史成功比例、上次状态和显示模式。只有实际显示非空例句时才记作语境模式；无例句词卡按纯单词模式生成预测和反馈。用历史反馈顺序更新受约束的权重，分别预测忘了、近似、记得的概率。近似对历史记忆程度和选词权重使用中间值0.5，原始训练标签仍是独立的近似状态；同时保留新词探索、熟词复现和最近词降权。

展示词卡时先冻结预测时间、目标时间、特征、模型版本和三种状态的概率；用户反馈后才追加实际状态和作答时间。训练只使用预测时点以前已发生的反馈，不能把之后的答案放进当时的特征。记录按唯一事件 ID 去重，不以累计正确率伪造过去的逐次训练样本。

未来日期预估假设其间没有新的复习。用户仅改变日期不会产生带答案的训练事件。没有带时间的逐词历史时，不虚构复习间隔；旧累计次数只在有明确截止时间的初始估计中使用。

评价使用每条事件保存的、实际作答前的三状态概率，报告三分类 Brier 误差（各类误差平方和）和对数损失，与三类均分概率基准比较，Brier基准为2/3。旧v1两状态事件保留原版本、概率及实际结果，继续参与训练，但不虚构第三类历史概率，也不混入v2误差。页面分别显示总训练样本数及三状态误差样本数。算法会更新，不等于准确率必然提高；尚无真实用户长期效果验证。

## 保存、同步与兼容

- 游客先在本机保存。登录后逐条事件同步到现有 Worker/D1，数据只归当前认证账号；语言分别统计与训练。
- `/api/vocab/reviews` 采用追加记录。写事件与增加统计在同一批事务中完成；重试相同 ID 不重复计数；下载按时间和 ID 分页，不截断为“最近500条”。
- 待同步事件保留在本地，恢复网络或后续反馈时重试。退出前保留账号隔离缓存，重新登录该账号恢复待同步记录。
- 旧 `/api/vocab` 继续兼容词汇量测量。游客旧累计迁移先扣除已经有逐次事件的部分，并使用固定迁移 ID 防止重试重复累计。
- `0006_vocabulary_reviews.sql` 为追加式迁移；旧词卡和既有账号统计不清空。
- 三状态升级不增加数据库表或字段，完整状态和三概率存入已有事件。累计已练次数加1，只有完全记得才增加旧正确计数；近似次数由独立事件汇总，游客迁移、同步重试和导出保留原状态。
- 可从背词页导出当前语言的个人学习事件 JSON，包括原预测与实际结果；不会把学习记录发布进公共仓库。

自动测试覆盖词库合并、来源完整性、时间隔离、学习后的参数变化、预测误差、同步重试、分页、账号隔离及事务回滚。最终构建、预览交互结果与当前提交见 [PR #23](https://github.com/Etymodes/PKUni_Latinex/pull/23)。真实账号跨设备、Firefox及长期学习效果只有实际验证后才能记为通过。
