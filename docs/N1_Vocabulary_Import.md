## 解析与规范化

每页以「词头后一行的词性」划定主词条，同时独立计算原页面 12 pt 词头行数。**230 页全部一致**，合计 2,014。搭配、相关词、近义词、反义词、惯用句、谚语均未冒充主词条，也没有因异常而跳过任何主词条。

- 去除音调编号、英文词源括注及排版空格。
- な形词的连体形式还原词干，如「鮮やかな」→「鮮やか」；名词兼な形词保留原词干。
- 显式的副词用法还原词干，如「交互に」→「交互」、「堂々と」→「堂々」；固定副词「一概に」「ろくに」不机械去掉尾字。
- 接头/接尾词的「～」是语法位置标记，移入说明，词性仍保留。
- 动词原辞书形保留；「適わない」这类所教意义依赖否定式的惯用表达保留其形式并修正词性。
- 每词只用一个主词头。并列写法保存于 `spellingVariants` 和 `notes`；读音变体保存于 `readingVariants` 与 `senses`，不同读音与释义保持对应。
- 「叶える」优先采用与原释义及原搭配一致的写法，原先并列的「適える」仍可追溯。「裂く／割く」在释义内明确写法对应。
- ID 为 `ja-n1-list-` 加 NFKC 词头的 SHA-1 前 12 位。没有随机编号，重跑不会改变既有规范词头的 ID。
- `context` 留空；原书搭配未作为已核验例句批量导入。中文释义以用户给定资料为基础，不以第三方词典释义替换整本词表。
