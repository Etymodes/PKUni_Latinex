# Pikku 自然习得、剧情与游戏化语言学习研究

版本：v1.0  
日期：2026-08-05  
状态：产品研究基线；不等于已经批准的功能规格

## 1. 结论

Pikku 不应把“自然习得”理解成“只要沉浸、不要讲解、不要背词”。更稳妥的产品闭环是：

> 可理解且有意义的输入 → 为完成任务而互动 → 产生必要输出 → 注意到语言形式 → 间隔提取与再次遇见

剧情和游戏主要解决“为什么要理解、为什么要继续”；题库、辞典和自适应背词解决“怎样把偶遇变成长期可提取的知识”。两者必须互通，不能用剧情包装与学习目标无关的点击奖励。

首个建议原型不是开放世界，也不是自由生成式聊天，而是每种已上线语言一章 8–12 分钟、可重复游玩的静态短任务。每章只引入少量新项目，有理解支援、三次有意义选择、一次输出修复和一次延迟复现。

## 2. “自然习得”包含哪些不同概念

中文语境常把三件事混称为自然习得：

1. 第一语言在生活互动中的自然获得；
2. Krashen 与 Terrell 的 Natural Approach，包括可理解输入、低焦虑和不强迫过早输出；
3. 广义的情境学习、沉浸、泛读、任务型学习和游戏化学习。

这三者不能画等号。成年人使用软件学习第二语言，不具备儿童第一语言习得的全天输入、照护关系和时间规模。Pikku 可以采用有用原则，但不能宣传“输入本身足以保证习得”或“显性语法一定妨碍习得”。

## 3. 证据如何转成产品原则

### 3.1 可理解输入是底座，但不是全部

Krashen 强调以理解信息为目的的输入和低压力环境；Loschky 的实验也表明，调整输入及互动有助于理解。但这不等于单向输入足以解释所有学习效果。

产品规则：

- 先让用户理解发生了什么和任务目的，再要求分析形式；
- 点击释义、慢速音频、句法分层和界面语言提示按需展开；
- 失败时先重述、补图示或缩小选择范围，再直接给答案；
- 独立泛读可把约 95%–98% 已知词覆盖作为分级启发式，而不是硬门槛。

### 3.2 互动的价值是协商意义

计算机媒介互动研究发现，学习者在完成共同任务时会请求澄清、确认理解并修复误解；真正参与协商的词更容易保留。协商加推动输出也有利于产出性词汇学习。

产品规则：

- 对话选项应改变任务信息，不只是正确／错误按钮；
- 用户可以选择“请换一种说法”“你的意思是……吗”“我不认识这个词”；
- NPC 先回应意义，再用重述和最小提示修正形式；
- 输出短而必要，例如复述线索、选择礼貌程度或补完关键信息。

### 3.3 注意形式和显性提示有价值

Schmidt 的 noticing 研究强调，学习者至少要注意到输入中的相关形式；VanPatten 的 processing instruction 则把显性提示用于改变输入处理方式，而不是脱离意义地背规则。

产品规则：

- 第一次出现不弹整页语法讲义；理解后再用“放大镜”指出决定意义的形式；
- 高亮必须服务于语义，例如日语作用域、西班牙语重音、拉丁语分词一致；
- 错后提示“刚才忽略了什么”，并给最小对比；
- 显性讲解可关闭，但考试模式可使用更直接的术语。

### 3.4 泛读和重复相遇形成语言感

分级阅读及阅读加听力研究显示，持续输入能带来词汇收益，但收益受既有词汇量和文本负担影响。“儿童母语读物”并不天然适合二语初学者。

产品规则：

- 同一词在不同人物、地点和任务中再次出现，不连续复制同一句；
- 回放可以切换轻松阅读、听读和侦探标注；
- 分支数量服从目标词的计划复现，不追求无限分叉；
- 高等级继续覆盖低等级核心词，符合现有累计词库逻辑。

### 3.5 间隔提取不能被“自然”排除

二语词汇实验表明，带反馈的提取练习与展开间隔结合更有利于保持。Pikku 现有自适应背词可以直接承接剧情学习。

产品规则：

- 场景中新遇见或误解的词进入“场景词包”，但只抽取最需要巩固的少量项目；
- 先以 D1／D3／D7 再现作为可解释默认值，未来用实际留存数据校准；
- 提取轮换词义、听辨、语境选义、搭配和短输出；
- 词卡显示来源章节和对话，恢复情境线索。

### 3.6 游戏机制必须进入核心学习行为

冒险游戏研究显示，游戏本身可带来词汇收益，但嵌入词汇聚焦练习后，即时和延迟测试往往更好。叙事角色扮演可能更有趣，却不一定有更高的单位时间学习效率。

产品规则：

- 核心谜题必须依靠理解语言解决；
- 经验值、签到和装饰只能辅助，不能替代语言决策；
- 同时衡量“愿不愿继续玩”和“过一周是否还能提取”；
- 不使用付费体力、惩罚性连续签到或操控依恋的角色奖励。

## 4. Pikku 的六段剧情学习环

### Hook｜进入问题

用人物目标、文化冲突、待修复文本或小谜题建立动机。用户先知道“为什么要读”。

### Explore｜可理解探索

阅读或听取经过分级的场景材料；可点词、重听、查看图像或简化重述。

### Negotiate｜协商意义

用户请求澄清、确认所指、排除歧义，NPC 根据请求换一种表达。

### Act｜用语言行动

选择能改变信息和后果的表达，或补完一段必要短输出。

### Notice｜回看关键形式

通关后聚焦一个真正改变意义的形式，显示最小对比和错因。

### Echo｜延迟回声

目标项目进入背词、错题或下一章，换人物与语境再次出现。

## 5. 可用于 Pikku 的游戏模式

### 5.1 剧情阅读

人物带来一封邮件、一页笔记或一段对话。用户通过阅读决定下一步，并可以切换轻量支援层。

### 5.2 语言侦探

从词形、语序、重音、敬语或词源关系中判断谁误解了信息。适合拉丁语句法、日语作用域和西班牙语语用。

### 5.3 文献修复

重排残缺句、恢复省略成分或判断不同版本。公共领域原文与现代版权注释必须分层。

### 5.4 中介任务

用户不是逐字翻译，而是向另一位角色解释关键信息。可测试理解、语域和跨文化差异。

### 5.5 受限对话

提供可编辑短语、澄清请求和复述，不在首版开放自由生成长对话。

## 6. 首批语言原型

### 拉丁语｜香山碑文与版本线索

- 目标：词典回溯、分词一致、间接陈述；
- 玩法：对照拓片记录和转录，识别哪处分析不可能；
- 回声：错误词形进入背词，句法错误进入错题。

### 日语｜被误读的研究会议邮件

- 目标：作用域、敬语、効率／精度／信頼性／効果；
- 玩法：澄清“提高的是哪一项”，修复一封可能引起误会的邮件；
- 回声：同一词在后续工作场景中换搭配复现。

### 西班牙语｜研究经历介绍的纠错

- 目标：no es A, sino B、介词、间接疑问；
- 玩法：帮助角色准确说明“眼动不是主要研究路径”；
- 回声：ser／estar、sino／sino que 进入最小对比复习。

### 古希腊语｜规划占位

- 阿提卡散文为形态和句法骨架；
- Homeric、Ionic、Aeolic、Doric 作为作者和体裁支线；
- 在 `grc` 数据模型与人工审核能力上线前，不假装已有完整课程。

## 7. 最小自适应规则

1. 根据账号词汇统计选择场景版本，而不是生成任意新文本；
2. 每章新项目控制在可理解范围内；
3. 请求释义、反复重听、答错或修复失败时提高相应项目权重；
4. 剧情完成后只抽取最需要巩固的项目进入背词；
5. 后续章节用不同人物和任务复现，不复制原句；
6. 允许手动选择“更沉浸／更多讲解”，不推断用户人格。

建议的最小场景元数据：

```text
scene_id / target_language / ui_locale / level / learning_objectives /
required_known_items / target_items / support_level / nodes / choices /
repair_prompts / review_links / content_review_status
```

## 8. 衡量标准

主指标：

- 场景理解题正确率；
- 目标项目 D1／D7／D30 的识别与产出保持；
- 同一知识在新情境中的迁移；
- 请求提示后能否完成修复；
- 自愿回放率和完成率。

护栏指标：

- 因新词过密、音频过快或说明过多而退出；
- 只靠反复猜选项通关；
- 游戏时长提高但延迟保持不变；
- 角色关系或奖励使用户感到被操控；
- 生成内容与审核解析冲突。

## 9. 分阶段建议

### M0｜静态数据原型

- 每种已上线语言一章静态短剧情；
- 使用现有角色、题库、辞典跳转和账号词汇统计；
- 无自由生成、无新后端服务；
- 比较普通题卡与剧情任务的完成率、提示使用和 D7 保持。

### M1｜自适应版本

- 同一场景按词库范围提供两到三个经人工审核的版本；
- 剧情错因进入背词权重；
- 增加回放时的听读和句法层。

### M2｜受限对话与联合学习

- 加入可编辑短语、澄清请求和复述任务；
- 首个跨语任务为拉丁语—西班牙语；
- 纳入文化中介，不把词源相似误写成现代语义相同。

### M3｜生成式扩展评估

- 只有在审核、追踪、年龄和隐私边界成熟后才评估生成式 NPC；
- 生成对话与事实解析分层，权威解析仍来自已审核内容；
- 用户能随时关闭剧情并回到纯学习台。

## 10. 待用户决定

1. 首批故事重心：建议 **70% 当代北京生活／学术小谜题 + 30% 历史文献支线**。
2. 用户身份：建议采用不预设性别、国籍和职业的第二人称“你”，只允许轻量自定义。
3. 单章长度：建议默认 **8–12 分钟**，另有 3 分钟快速复习和 20 分钟深读版本。

这三项确认前，只把研究结论写入路线图，不开发大型剧情引擎。
