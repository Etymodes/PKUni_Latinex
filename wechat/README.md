## 构建与导入

在仓库根目录执行 `npm ci`，随后运行 `npm run build:wechat`。构建从 `app/page.tsx` 的题库组合和既有 TS 数据中提取内容；不下载或引入额外教材。Sharp 仅在构建时把原有等级 SVG 转为 PNG。TS/JSON 内容及预测算法均由同一源代码生成。生成的 `wechat/miniprogram/data` 和 `assets` 不提交 Git。

微信开发者工具导入 **`wechat` 目录**，其 `project.config.json` 已配置用户确认的 Pikku AppID。不能把 Next.js 根目录当成小程序导入，不需要在微信工具中“构建 npm”。开发者私有配置不提交。

## 同步与故障行为

答题与收藏仍在网站确认后更新统计。背词反馈先按账号独立保存到本机，再将有稳定事件 ID 的追加记录同步；断网或回包丢失时保留待同步队列，刷新时重试且不会重复累计。新反馈只调用 `/api/vocab/reviews`，不再重复调用旧词汇累计接口。历史二态事件和累计统计保留，近似增加已练次数但不增加记得次数。

游客可离线练习，词条记录独立保存在游客空间，不自动并入登录账号。刷新、重新进入小程序会读取云端记录，退出或换号时丢弃上一账号响应和展示中的旧预测。词典查看本身不产生学习反馈。

收藏保存前先读取最新云端列表，只替换所选语言的收藏，以免覆盖其他语言。现有接口是按语言整组替换，没有版本锁；同一语言跨设备恰好同时写入仍可能由最后一次请求覆盖，和现有网站接口能力一致。

网站管理员覆盖题目后，刷新会应用修改与删除并清空正在进行的旧题队列。题库源码新增内容则需要重新构建、上传小程序版本。
